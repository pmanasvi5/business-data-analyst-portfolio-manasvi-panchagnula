## How I Approach Analysis

1. Define the business question and the decision the analysis should support.
2. Inspect, clean, and validate the data.
3. Explore patterns, define useful metrics, and test assumptions.
4. Communicate findings through clear visuals and concise recommendations.
5. Reflect on limitations, lessons learned, and possible next steps.
