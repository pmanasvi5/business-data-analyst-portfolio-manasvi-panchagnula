# Project Case Studies

Each project in this folder should have its own directory and a `README.md` based on [PROJECT_TEMPLATE.md](PROJECT_TEMPLATE.md).

Suggested naming style:

```text
projects/
├── PROJECT_TEMPLATE.md
├── customer-churn-analysis/
│   └── README.md
├── sales-performance-dashboard/
│   └── README.md
└── operations-process-improvement/
    └── README.md
```

Use short, descriptive, lowercase folder names separated by hyphens. Include only data and materials you are allowed to publish.
